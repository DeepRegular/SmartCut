# プロジェクト（作業の保存）

[← ドキュメント](../README.ja.md) ・ [← SmartCut](../../README.ja.md) ・ [English](projects.md)

録画を 20 本並べて 1 本ずつ CM を切っている途中で用事ができ、ウィンドウを
閉じることになっても、作業は消えません。

**プロジェクトファイル（`.scproj`）に、一覧の中身をまるごと保存できます。**
どの録画を並べたか、それぞれどこを切ったか、どこへ書き出す設定にしたかが
残り、次に開けば、閉じたときのままの画面から続けられます。

## 保存する・開く

![SmartCut メニュー](../images/usage-menu.ja.png)

一覧ウィンドウの右上にある **SmartCut** ボタンを押すと、次の 4 つが出てきます。
キーボードでも同じ操作ができます。

| キー | ボタン | すること |
|---|---|---|
| `Ctrl+S` | プロジェクトを保存 | 上書き保存します |
| `Ctrl+Shift+S` | 名前を付けて保存 | 別名で保存します |
| `Ctrl+O` | プロジェクトを開く | 保存したものを読み込みます |
| `Ctrl+N` | 新規作成 | 一覧を空にして、最初からやり直します |

`新規作成` を選ぶと、一覧が空になり、出力設定も初期状態に戻ります。起動した
直後とまったく同じ状態です。保存していない作業があるときは、消してよいかを先に
確認します。

メニューの一番下は `終了` です。ウィンドウの `×` と同じで、保存していない作業が
あれば同じように確認します。バッチ出力ツールのメニューにもあります。

保存したファイルは、ウィンドウにドラッグ＆ドロップしても開けます。
コマンドラインから渡すこともできます。

```bash
smartcut 金曜の分.scproj
```

## 保存されるもの・されないもの

保存されるのは、**自分で決めたこと**だけです。

- 並べた録画の場所（一覧の順番も）
- 変更したクリップ名
- それぞれに入れたカットとキーフレーム（印）
- カット編集で開いた録画については、そこで出ていた検出結果（CM・黒・白・無音の
  区間）。タイムラインの帯は、次に開いたときもそのまま戻ります
- 書き出すトラックの選び方
- ディスクから読んだ録画の番組名とチャプター、およびディスクとして書き出すときに
  各録画へ書く内容（番組名・チャンネル・録画日時・番組内容。打ち直したものも含む）
- 出力設定（いちど設定したもの）

逆に、あとから調べ直せるものは保存しません。録画の長さ・解像度・フレーム
レートなどは、次に開いたときにファイルを読めば分かります。早送り用の索引や
サムネイルは SmartCut の作業用フォルダーにあり、そこから読み直します。

検出結果も同じ作業用フォルダーに残りますが、そちらはこのパソコンの中だけの
ものです。カット編集で開いた録画は、プロジェクトにも区間が書かれます。作業用
フォルダーを消しても、別のパソコンで開いても、帯はそのまま出ます。

そのため `.scproj` は小さいままです。カットと印だけなら 20 本分の一覧でも
数百バイト、検出結果が入っても数キロバイトです。中身は文字だけなので、別の
パソコンに持っていっても開けます。足りないものはそのとき読み直すだけなので、
作業用フォルダーを消したあとでも開けます。

### 出力設定は、設定したあとだけ保存されます

入力画面のまま保存したプロジェクトには、出力の指定がありません。その時点で
出力設定にあるのは、初期値と、環境設定で決めた書き出し名と、前回から引き継いだ
設定だけです。どれもこの作業について決めたことではないので、書き込みません。
あとで開いたときは、その時点の初期値と環境設定をもう一度読みます。設定を変えた
あとなら、新しいほうが使われます。

出力設定画面で何かひとつ操作すれば、そこから先は画面全体がこのプロジェクトの
設定として扱われます。保存され、開いたときにそのまま戻ります。画面を開いただけでは
操作したことになりません。フォルダー名やディスク名は録画から自動で埋まるもの
で、次に開いたときもまた埋まります。

バッチ出力だけは別です。ジョブは、いまのウィンドウで書き出すのと同じ結果を出す
ものなので、`バッチに登録` では出力設定画面を開いていなくても、キューに渡す
複製に出力設定を書き込みます。

## タイトルバーの `*` は「まだ保存していない」印

タイトルバーには、いま開いているプロジェクトの名前が出ます。保存していない
変更があるあいだは、名前の前に `*` が付きます。この状態でウィンドウを閉じようと
すると、「保存しますか」と確認します。

`*` は、**いまの一覧と、最後に保存した内容を毎回見比べて**付けています。
「何か操作したから付ける」のではありません。ですから、カットを入れてすぐ取り
消したときのように、結果的に元どおりになった場合は `*` が消えます。

例外が 2 つあります。どちらも「`*` が出るのはおかしい」場面です。

- 一覧が空で、プロジェクトも開いていないとき。保存すべきものが無いので `*` は
  付きません。
- コマンドラインでファイルを渡して起動したとき。その一覧は画面で組んだ
  ものではなく、同じコマンドを打てばまた同じものが出てきます。ですから、
  何も触っていないうちは `*` が付きません。

## 録画ファイルが移動していたとき

プロジェクトに書かれた録画が、別のフォルダーへ移されていたり、消えていたりする
ことがあります。そのときも、**プロジェクト自体はふつうに開きます。**
見つからなかった録画の行にだけ、そのことが表示されます。残りの 19 本は今までどおり
使えます。

## 保存したプロジェクトは、そのままバッチのジョブになる

`出力` 画面の `バッチに登録` を押すと、いまの一覧がその場で保存され、キューの
末尾に入り、バッチ出力ツールが立ち上がります。保存の画面は出ません。一晩かけて
順に書き出すのは、別ウィンドウ・別プロセスで動くそのツールです。

キューに並ぶのは複製です。キューは専用の保存場所にいまの一覧を書き、それを実行
します。名前は、開いているプロジェクトがあればその名前、無ければ一覧の先頭の行の
名前です。複製はキューが管理するもので、ジョブを削除すると一緒に消えます。複製の
ほうを編集したいときは、ツールの行から `プロジェクトを開く` を選んでください。

**登録は保存でもあります。** 開いているプロジェクトがあれば、そのファイルにも
書きます。無題の一覧なら、複製が書き出されたことをもって保存済みとして扱います。
どちらもタイトルバーの `*` は消えます。ただし無題のまま登録した一覧は、キューから
外すと複製ごと消えます。あとで開き直したいものは `名前を付けて保存` で手元にも
残してください。プロジェクトに必要なものは全部 `.scproj` に入っているので、
ジョブの中身はそのファイル 1 つだけです。
[まとめて処理する](batch.ja.md#一晩かけてプロジェクトを順に処理する)を
見てください。

## 新しいバージョンで作ったファイル

`.scproj` にはバージョン番号が入っています。**いま使っているものより新しい
バージョンで保存されたファイルは、読み込みを受け付けません。**

無理に読み込むと、こちらが解釈できない項目は警告なく捨てられます。そのまま上書き
保存すれば、その作業は本当に消えます。カットを警告なく捨てるくらいなら、開けない
ほうがましだ、という判断です。

なお、項目が増えただけならバージョンは上がりません。解釈できない項目は、その
まま残して書き戻します。
