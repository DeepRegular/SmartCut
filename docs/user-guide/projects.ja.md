# プロジェクト

[← ドキュメント](../README.ja.md) ・ [← SmartCut](../../README.ja.md) ・ [English](projects.md)

一晩ぶんの作業は、録画の一覧と、それぞれから切り取った内容と、結果の出力先の
3 つでできています。プロジェクトファイル（`.scproj`）はこれらをまとめて保存し、
あとから作業を再開できるようにします。

プロジェクトが無かった頃は、プログラムを閉じると作業が消えていました。1 本を
その場で切るだけなら困りませんが、週末に 20 本を扱うとなると大きな損失です。

## 保存と読み込み

| | |
|---|---|
| `Ctrl+N` | 新規作成 |
| `Ctrl+S` | プロジェクトを保存 |
| `Ctrl+Shift+S` | 名前を付けて保存 |
| `Ctrl+O` | プロジェクトを開く |

同じ 4 項目は、一覧ウィンドウ右上の **SmartCut** メニューにもあります。環境設定や
バージョン情報と同じ場所です。ここは、個々のクリップではなくプログラム全体に
関わる項目を集めた場所になっています。

**新規作成** は一覧を空にし、出力設定を初期状態に戻し、開いていたプロジェクト
ファイルとの結び付きを切ります。起動直後と同じ状態です。保存していない作業が
あるときは、その前に確認を出します。

`.scproj` はウィンドウにドロップしても開きますし、コマンドラインからも開けます。

```bash
smartcut 金曜の分.scproj
```

## ファイルに入っているもの

プロジェクトが保持するのは、あとから割り出せないものだけです。

- 各録画のパス（一覧の順序込み）
- それぞれに入れたカットとキーフレーム
- 書き出すトラックの選択
- ディスクの索引に書かれていた番組名とチャプター（開き直すときに、ディスクを
  ドライブへ入れ直さずに済むようにするため）
- 出力設定

それ以外は入れません。録画の尺・解像度・フレームレートは、シーク用インデックスと
一緒に得られるからです。シーク用インデックスと CM 検出の結果は、プログラム自身の
キャッシュディレクトリに置いています。録画の隣に置かないのは、録画の置き場所が
たいてい他のプログラムも読む共有だからです。

つまり、ファイルの中身はパスと編集内容と設定だけです。**20 本ぶんの一覧でも数百
バイト**にしかならず、開いたときの動作は、同じファイル群をあらためて追加したとき
とまったく同じになります。

狙いは容量の節約ではありません。**別のマシンでも、キャッシュを消したあとでも
開ける**ことです。足りないものは読み直せばよいだけだからです。

## タイトルバーの `*`

タイトルバーには開いているプロジェクトの名前が出ます。ディスクに書いていない
作業があるあいだは頭に `*` が付き、その状態でウィンドウを閉じようとすると確認を
求めます。

**未保存かどうかは、記憶するのではなく突き合わせて判定しています。** SmartCut は
「いまこの瞬間に書き出したらプロジェクトはどうなるか」を作り、最後に書いた／
読んだ内容と比較します。

もう一方のやり方、つまり変更のたびにフラグを立てる方式では、作業を元に戻す操作の
すべてでフラグを下ろさなければなりません。編集画面をキャンセルで抜けたとき、
クリップを足してすぐ消したとき、などです。1 か所でも忘れると、失うものが無いのに
「失われます」と言い続けるプログラムになります。そうなると、人は確認ダイアログを
読まなくなります。

比較の対象から意図的に外しているものが 2 つあります。1 つは保存時刻です。毎回
変わるうえに、作業内容については何も表していません。もう 1 つは「検出結果の印が
まだタイムラインに反映されていないか」を表すフラグです。これはファイルに書き
ますが、失われることはありません。対応する検出結果はキャッシュにあるからです。

例外的な扱いが 2 つあります。

- **プロジェクトを開いていない空の一覧は、失うものが無い**という扱いにします。
  直前に何が入っていたかは関係ありません。これが無いと、一覧を空にしたあとに
  `*` が消せなくなります。保存するものが無いので、保存しても `*` が消えないから
  です。
- **コマンドラインで渡された一覧は、誰かが行った作業ではありません。** 同じ
  起動をすれば同じ一覧になるので、その一覧をタイトルバーの比較対象にします。
  フォルダーを指定して起動したときに、誰も触っていない一覧の上に `*` が出ては
  おかしいからです。

## ファイルが移動していたとき

ファイルに書かれた録画が移動していたとしても、プロジェクト全体を開けなくする
理由にはなりません。その行もほかと同じように一覧に載り、何が起きたかは索引作りの
段でその行に表示されます。問題の無かった 19 本と並んだままです。

## バージョン

フォーマットにはバージョン番号があり、未来のバージョンのファイルは読まずに
拒否します。新しいファイルを無理に読み込めば、このプログラムが理解できない部分が
そのまま失われます。誰かのカットを黙って捨てるくらいなら、開けないほうがましです。

フィールドの**追加**はバージョンの変更にあたりません。読み手は、知らない
フィールドをそのまま残します。

設定はキーごとにコピーします。丸ごと取り込まないので、出力設定の画面に対応する
コントロールが無い値が、ファイルから入り込むことはありません。選択肢に無い値を
渡されたドロップダウンは、先頭の項目に戻ります。画面に出ている内容と、実際に
書き出される内容は、常に一致していなければならないからです。
