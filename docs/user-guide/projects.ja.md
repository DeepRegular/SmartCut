# プロジェクト

[← ドキュメント](../README.ja.md) ・ [← SmartCut](../../README.ja.md) ・ [English](projects.md)

一晩ぶんの作業とは、録画の一覧と、それぞれから何を切り取ったかと、結果をどこへ
出すかの組み合わせです。プロジェクトファイル（`.scproj`）はそれをまとめて保存し、
あとから続きを再開できるようにします。

プロジェクトが無かった頃は、プログラムを閉じると作業が失われました。1 本を
その場で切るだけならそれで困りませんが、週末に 20 本を扱う場合は大きな損失です。

## 保存と読み込み

| | |
|---|---|
| `Ctrl+S` | プロジェクトを保存 |
| `Ctrl+Shift+S` | 名前を付けて保存 |
| `Ctrl+O` | プロジェクトを開く |

同じ 3 項目は一覧ウィンドウ右上の **SmartCut** メニューにもあります。環境設定や
バージョン情報と同じ場所で、そこは「個々のクリップではなくプログラムについての
項目」が集まっているところです。

`.scproj` はウィンドウにドロップしても開きますし、コマンドラインからも開けます。

```bash
smartcut 金曜の分.scproj
```

## ファイルに入っているもの

プロジェクトが保持するのは、あとから割り出せないものだけです。

- 各録画のパス（一覧の順序込み）
- それぞれに入れたカットとキーフレーム
- 書き出すトラックの選択
- ディスクの索引が語っていたこと——番組名とチャプター。開き直すのにディスクを
  もう一度ドライブに入れなくて済むようにするためです
- 出力設定

それ以外は入れません。録画の尺・解像度・フレームレートはシーク用インデックスと
一緒に得られます。シーク用インデックスと CM 検出の結果はプログラム自身の
キャッシュディレクトリにあります。録画の隣ではなくキャッシュに置くのは、録画の
置き場所がたいてい他のものも読む共有だからです。

つまりファイルの中身はパスと編集内容と設定だけです。**20 本ぶんの一覧でも数百
バイト**にしかならず、開いたときの動作は同じファイル群を追加したときとまったく
同じになります。

これは容量の節約が目的ではありません。**別のマシンでも、キャッシュを消した
あとでも開ける**ことが目的です。読み直せばよいだけだからです。

## タイトルバーの `*`

タイトルバーには開いているプロジェクトの名前が出ます。ディスクに書いていない
作業があるあいだは頭に `*` が付き、その状態でウィンドウを閉じようとすると確認を
求めます。

**未保存かどうかは、記憶するのではなく突き合わせて判定しています。** SmartCut は
「いまこの瞬間に書き出したらプロジェクトはどうなるか」を作り、最後に書いた／
読んだ内容と比較します。

もう一方のやり方、つまり変更のたびにフラグを立てる方式には、作業を元に戻す
すべての操作でフラグを下ろす必要があります。編集画面をキャンセルで抜けたとき、
クリップを足してすぐ消したとき、などです。1 か所でも忘れると、失うものが無いのに
「失われます」と言い続けるプログラムになります。そうなると人は確認ダイアログを
読まなくなります。

比較の対象から意図的に外しているものが 2 つあります。1 つは保存時刻で、毎回
変わるうえに作業内容について何も語りません。もう 1 つは「検出結果の印がまだ
タイムラインに反映されていないか」を表すフラグです。これはファイルに書きますが、
失われることはありません。対応する検出結果はキャッシュにあるからです。

端の場合に対する例外も 2 つあります。

- **プロジェクトを開いていない空の一覧は、失うものが無い**という扱いにします。
  直前に何が入っていたかは関係ありません。これが無いと、一覧を空にしたあとに
  `*` が消せなくなります。保存するものが無いので、保存しても `*` が消えないから
  です。
- **コマンドラインで渡された一覧は、誰かが行った作業ではありません。** 同じ
  起動をすれば同じ一覧になるので、その一覧をタイトルバーの比較対象にします。
  フォルダーを指定して起動したときに、誰も触っていない一覧の上に `*` が出ては
  おかしいからです。

## ファイルが移動していたとき

ファイルに書かれた録画が移動していたとしても、プロジェクト全体を開けなくする
理由にはなりません。その行もほかと同じように一覧に載り、索引作りの段で何が
起きたかがその行に表示されます。問題の無かった 19 本と並んだままです。

## バージョン

フォーマットにはバージョン番号があり、未来のバージョンのファイルは読まずに
拒否します。新しいファイルを無理に読み込んだときに失われるのは、まさにこの
プログラムが理解できない部分です。誰かのカットを黙って捨てるくらいなら、開けない
ほうがましです。

フィールドの**追加**はバージョンの変更にあたりません。知らないフィールドは
そのまま残されます。

設定はキーごとにコピーします。丸ごと取り込まないので、出力設定の画面に対応する
コントロールが無い値がファイルから入り込むことはありません。選択肢に無い値を
渡されたドロップダウンは先頭の項目に戻ります。画面に出ている内容と実際に
書き出される内容は、常に同じ答えでなければならないからです。
