# プロジェクト（作業の保存）

[← ドキュメント](../README.ja.md) ・ [← SmartCut](../../README.ja.md) ・ [English](projects.md)

録画を 20 本並べて、1 本ずつ CM を切っていく。途中で用事ができた。
そこで閉じても、作業は消えません。

**プロジェクトファイル（`.scproj`）に、一覧の中身をまるごと保存できます。**
どの録画を並べたか、それぞれどこを切ったか、どこへ書き出す設定にしたか。
次に開けば、閉じたときのままの画面から続けられます。

## 保存する・開く

![SmartCut メニュー](../images/usage-menu.ja.png)

一覧ウィンドウの右上にある **SmartCut** ボタンを押すと、次の 4 つが出てきます。
キーボードでも同じことができます。

| キー | ボタン | すること |
|---|---|---|
| `Ctrl+S` | プロジェクトを保存 | 上書き保存します |
| `Ctrl+Shift+S` | 名前を付けて保存 | 別名で保存します |
| `Ctrl+O` | プロジェクトを開く | 保存したものを読み込みます |
| `Ctrl+N` | 新規作成 | 一覧を空にして、最初からやり直します |

**新規作成**を選ぶと、一覧が空になり、出力設定も初期状態に戻ります。起動した
直後とまったく同じ状態です。保存していない作業があるときは、消してよいかを先に
確認します。

保存したファイルは、ウィンドウにドラッグ＆ドロップしても開けます。
コマンドラインから渡すこともできます。

```bash
smartcut 金曜の分.scproj
```

## 保存されるもの・されないもの

保存されるのは、**あなたが決めたこと**だけです。

- 並べた録画の場所（一覧の順番も）
- 変更したクリップ名
- それぞれに入れたカットとキーフレーム（印）
- 書き出すトラックの選び方
- ディスクから読んだ録画の番組名とチャプター、およびディスクとして書き出すときに
  各録画へ書く内容（番組名・チャンネル・録画日時・番組内容。打ち直したものも含む）
- 出力設定

逆に、**あとから調べ直せるもの**は保存しません。録画の長さ・解像度・フレーム
レートなどは、次に開いたときにファイルを見れば分かります。早送り用の索引や
CM 検出の結果は、SmartCut が自分の作業用フォルダーに置いていて、そこから
読み直します。

そのため `.scproj` はとても小さく、**20 本ぶんの一覧でも数百バイト**にしか
なりません。中身は文字だけなので、別のパソコンに持っていっても開けますし、
作業用フォルダーを消したあとでも開けます。足りないものは、そのとき読み直す
だけだからです。

## タイトルバーの `*` は「まだ保存していない」印

タイトルバーには、いま開いているプロジェクトの名前が出ます。保存していない
変更があるあいだは、名前の前に `*` が付きます。この状態でウィンドウを閉じようと
すると、「保存しますか」と確認します。

`*` は、**いまの一覧と、最後に保存した内容を毎回見比べて**付いています。
「何か操作したから付ける」のではありません。ですから、カットを入れてすぐ取り
消したときのように、結果的に元どおりになった場合は `*` が消えます。

例外が 2 つあります。どちらも「`*` が出るのはおかしい」場面です。

- **一覧が空で、プロジェクトも開いていないとき。** 失うものが無いので `*` は
  付きません。
- **コマンドラインでファイルを渡して起動したとき。** その一覧はあなたが作った
  ものではなく、同じコマンドを打てばまた同じものが出てきます。ですから、
  何も触っていないうちは `*` が付きません。

## 録画ファイルが移動していたとき

プロジェクトに書かれた録画が、別のフォルダーへ移されていたり、消えていたりする
ことがあります。そのときも、**プロジェクト自体はふつうに開きます。**
見つからなかった録画の行にだけ、そのことが表示されます。残りの 19 本は今までどおり
使えます。

## 新しいバージョンで作ったファイル

`.scproj` にはバージョン番号が入っています。**いま使っているものより新しい
バージョンで保存されたファイルは、開かずに断ります。**

無理に読み込むと、こちらが知らない項目は黙って捨てられます。そのまま上書き保存
すれば、その作業は本当に消えます。誰かのカットを黙って捨てるくらいなら、開けない
ほうがましだ、という判断です。

なお、項目が**増えただけ**ならバージョンは上がりません。知らない項目は、そのまま
残して書き戻します。
