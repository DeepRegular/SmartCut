# コマンドラインで使う

[← ドキュメント](../README.ja.md) ・ [← SmartCut](../../README.ja.md) ・ [English](cli.md)

GUI の中で動いているのと**同じエンジン**を、コマンドとしても使えます。
配布物では `smartcut-cli` という名前で入っています（Windows では
`smartcut-cli.exe`、tar.gz では展開したフォルダーの `./smartcut-cli`）。
`smartcut` のほうは GUI です。ソースからビルドしたときのコマンド名は `smartcut` で、
このページの例もそちらで書いています。

決まった処理を繰り返すとき、スクリプトから呼ぶとき、あるいは画面を出せない
サーバーで使うときのためのものです。できることは GUI と同じです。

## まず、この 6 つ

```bash
smartcut input.ts --keep 5.3-12.7 -o out.ts   # この区間だけ残す
smartcut input.ts --cut 8.0-20.0  -o out.ts   # この区間を削除する
smartcut input.ts --analyze                   # 何が起きるかを表示するだけ

smartcut input.ts --analyze --detect-cm --logo  # CM の候補を一覧する
smartcut input.ts --analyze --scenes            # 場面の変わり目を一覧する

smartcut input.ts --cut 8.0-20.0 --bdav ~/disc  # ファイルではなくディスクに書く
```

- `--keep` と `--cut` は何回でも書けます。`--keep 0-60 --keep 180-240`
  のように並べれば、その 2 区間が残ります。
- 時刻は秒数のほか、`1:23:45.6` の形でも書けます。
- **`--analyze` はカットを書きません。** どこをコピーしてどこを作り直すかの計画だけを
  表示します。まずこれで確かめてから本番を走らせるのが安全です。
  （`--seek-index` のように、ほかのオプションが書くファイルは書きます）
- `smartcut --help` で、すべてのオプションを用途ごとに分けて一覧できます。

## 切る場所を指定する

| オプション | 意味 |
|---|---|
| `--keep 開始-終了` | 残す区間。複数指定できます |
| `--cut 開始-終了` | 削除する区間。複数指定できます。`--keep` とは併用できません |
| `--no-open-gop` | 途中から始まるキーフレームを、コピーの開始点として使いません |
| `--clean-joins` | 各区間の先頭で最大 2 秒分を余分に作り直し、フレームの表示順が入れ替わらない位置まで進みます。その 2 秒がコピーではなくなるため、**既定では使いません**（詳しくは下の注を見てください） |

> `--clean-joins` を既定にしていない理由は次のとおりです。通常の継ぎ目でも、
> コピーしたフレームそのものは元と完全に同じで、ずれるのは表示される順番だけです。
> `--clean-joins` はそのずれを避けるために 2 秒を作り直しますが、その 2 秒は
> 元のコピーではなくなります（元に対して約 51 dB）。つまり劣化は確実に起きる一方で、
> ずれが直るとはかぎりません。この釣り合いを考えて、既定ではオフにしてあります。

## 出力先を決める

| オプション | 意味 |
|---|---|
| `-o 出力パス`（`--output` も可） | 出力先。**コンテナ（ファイルの形式）は拡張子で決まります**。このマシン上のファイルに限ります。読み込んでいる録画そのもの（とそのリンク）は指定できません。どちらも書き始める前にエラーになります |
| `--drop-stream 番号` | 録画のストリームを 1 本、出力から外します。複数指定できます。カット編集画面のトラックメニューと同じものです。放送録画の音声トラックのうち、残す範囲に何も入っていないもの（前の番組にだけあった副音声など）は、指定しなくても外し、その旨を表示します |
| `--title 番号` | ディスク（フォルダーでも `.iso` でも）の何番目の録画を開くか。番号のかわりに番組名の一部でも指定できます。省くと、中身を一覧表示して終わります |

## 複数の録画をまとめる

| オプション | 意味 |
|---|---|
| `--join 録画` | 同じ出力へ続けて書く録画です。**複数指定できます。** 指定した順に並びます |
| `--master 番号` | 出力の仕様（解像度・フレームレート・コーデック・音声トラック・テーブル）をどの録画に合わせるか。先頭を 1 と数えます。**省略すると先頭です**。録画の数より大きい番号はエラーになります |

`--keep` と `--cut` は先頭の録画に対する指定です。`--join` で足した録画は全編が
入ります。ファイルごとに区間を書けるコマンドラインは、書きにくいプロジェクト
ファイルにしかなりません。カット入りのリストはウィンドウで扱います。

```bash
smartcut part1.ts --join part2.ts --join part3.ts -o whole.ts
```

基準と仕様の合わない録画は、復号して基準の形に書き直します。拡大縮小、
レート変換、音声の再エンコードです。どれをなぜ書き直すのかは、1 バイトも書く
前に知らせます。仕様の合う録画はこれまでどおりスマートレンダリングされます。

## 継ぎ目のトランジション

| オプション | 意味 |
|---|---|
| `--transition 種類` | `none`、`fade-black`、`fade-white`、`dissolve`、`wipe-left\|right\|top\|bottom`、`slide-left\|right\|top\|bottom`。クリップ間の**すべての**継ぎ目に適用します |
| `--transition-seconds 秒` | 適用時間。30 秒まで。省略すると 1 秒です |
| `--transition-easing 曲線[:モード]` | 曲線は `none`、`back`、`bounce`、`circle`、`elastic`、`exponential`、`power`、`sine`、`quadratic`、`cubic`、`quartic`、`quintic`。モードは `:in`、`:out`、`:in-out`、`:out-in`。既定は `none:in` で等速です。一覧に無い名前はエラーになります |
| `--transition-image ファイル` | 各継ぎ目に重ねる静止画。効果の始まりで現れ、終わりで消えます |

この 4 つと `--join-fade-out`・`--join-fade-in` は継ぎ目に対する指定です。
`--join` なしで指定すると、無視せずにエラーにします。

```bash
smartcut a.ts --join b.ts --transition dissolve --transition-seconds 2 \
  --transition-easing sine:in-out -o joined.ts
```

**フェードは出力の長さを変えません。** 前後から半分ずつ使うためです。
**それ以外は指定秒数だけ出力が短くなります。** 2 本が同時に映るためです。

トランジションの範囲は全フレームを書き直します。どちらの録画にも無いフレーム
だからです。2 秒を指定すれば継ぎ目ごとに 2 秒ぶんのエンコードが発生し、それ
以外の場所は変わりません。音声はミックスしません。2 本が重なる効果では、手前の
クリップの音が効果のあいだも鳴り続けます。フェードでは、真ん中（色だけになる
ところ）で音が切り替わります。切り替わりを和らげたいときは `--audio-fade` を
使います。

## 音声

既定では、音声も映像と同じく**継ぎ目の数フレームだけ**を作り直します
（スマートレンダリング）。下の 5 つのうち 1 つでも録画と違う値を指定すると、
コピーできるフレームが無くなるので、トラック全体が再エンコードになります。

| オプション | 意味 |
|---|---|
| `--audio-mode smart\|copy\|reencode` | 既定は `smart`。継ぎ目にかかるフレームだけを作り直すので、切った側の音が漏れません。継ぎ目が無音なら 1 フレームも作り直しません。`copy` はバイト単位で無劣化ですが継ぎ目に音が少し残り、`reencode` はサンプル単位で正確に切れる代わりに全編を作り直します |
| `--audio-codec source\|aac\|lpcm\|ac3\|dts` | 書き出す音声の種類。既定の `source` は録画のままです。AAC はスマホでもそのまま再生でき、AC-3 と DTS は AV アンプで確実に再生でき、リニア PCM は非圧縮です |
| `--audio-channels 数` | チャンネル数（1〜8）。録画と違う数を指定するとダウンミックスになります（5.1ch をステレオに畳む、など） |
| `--audio-samplerate レート` | サンプリング周波数。`48k` でも `48000` でも書けます。コーデックによって扱えるレートが違い（AC-3 は 3 種類、Blu-ray の LPCM は別の 3 種類）、扱えないものを指定した場合は、最も近い値に補正したうえで、その旨を表示します |
| `--audio-bits 16\|24` | 1 サンプルの大きさ。リニア PCM のときだけ意味を持ちます。ほかのコーデックは音そのものではなく音の表現方法を記録するので、ビット数を書く場所がありません |
| `--audio-bitrate レート` | 再エンコードするときのビットレート。`192k` でも `192000` でも書けます。省くと録画に合わせます。エンコーダが受け付けない値は、そのコーデックが通常使う値まで引き上げたうえで、その旨を表示します |
| `--aac auto\|mpeg2\|mpeg4` | 書き出す AAC をどちらの規格として記録するか。既定の `auto` は録画に合わせます（放送なら MPEG-2 AAC） |
| `--audio-es` | 音声を素のファイルとしても書き出します。出力と同じ名前で、AAC のときだけです |
| `--sound-only` | 映像を書かず、音声だけのファイルを出力します。カットも結合も継ぎ目のフェードもそのまま入ります。映像は読みも書きもしないので短時間で終わります。拡張子で形式が決まります（`.aac` `.ac3` `.mp2` `.mp3` `.dts` `.m4a` `.wav`）。`.wav` は、`--audio-codec` でほかのコーデックを指定しないかぎりリニア PCM で書きます。拡張子の形式に入らない音声のときは、書き始める前にエラーで止まります。音声トラックは 1 本だけで、`--master` で指定した録画のトラックを基準にします。`--bdav`・`--video-share`・`--audio-es` とは併用できません。音声の無い録画を結合したときは、その録画の分を飛ばし、その旨を表示します |
| `--audio-fade 秒数` | 継ぎ目の手前で音を下げ、継ぎ目の先で戻します。0〜10 秒、既定は 0（フェードなし）|
| `--join-fade-out 秒数` | クリップの終わりで音を消すまでの秒数。`--join` でつなぐときの継ぎ目に掛かります。0〜10 秒、既定は 0 |
| `--join-fade-in 秒数` | 次のクリップの頭で音が戻るまでの秒数。同上 |

> **クリップの継ぎ目は前後を別々に指定します。** 終わるほうの番組をどう終わらせ
> るかと、始まるほうをどう始めるかは別の問いだからです。`--join-fade-out 3`
> `--join-fade-in 0` なら、手前の番組は 3 秒かけて消え、次の番組は頭から普通に
> 始まります。1 本の録画の中のカット点には `--audio-fade` が掛かります。
>
> `--audio-fade` と `--join-fade-*` が効くのは、音を書き直すときだけです。
> `smart` と `reencode` では掛かり、`copy` では掛かりません。
> 無劣化のまま運ぶ音声（TrueHD、DTS-HD MA）も
> 書き直さないので掛かりません。掛からなかったときはその旨を表示します。
> フェードは 2 つの断片をつなぐ場所のためのものなので、出力の先頭と末尾には
> 掛かりません。

## 放送 TS として書く

| オプション | 意味 |
|---|---|
| `--tables partial\|broadcast\|muxer` | TS の中身を説明するテーブルを、どの形で入れるか。指定が無ければ `.ts` は `broadcast`（録画自身の SDT・EIT・TOT。プレーヤーはここから番組名・放送局名・時刻を読みます）、`.m2ts` は `partial`（**部分 TS**。ディスクのストリームの書き方）になります。`muxer` は何も足しません。`--no-tables` は `muxer` の古い名前です |
| `--no-data-broadcast` | 録画のデータ放送（d ボタンで見られるページ）を捨てます。指定が無ければ残します。残せるのは、テーブルを muxer に任せない（`broadcast` か `partial` の）`.ts` だけです。`.m2ts` には入れる場所がありません。モジュールが欠けずにそのままのバイトで入るので、受信機は同じページを描きます。捨てて得られるのはファイルサイズの削減だけです。カルーセルは多重化全体の 1/100 から 1/5 を占めます。`--data-broadcast` は残すことを明示的に指定する書き方で、格納できなかったときのメッセージだけが変わります |

## ディスク（BDAV）として書く

`--bdav` を使うと、ファイルではなく**レコーダーが BD-RE に書くのと同じ形**の
フォルダーに書き出します。ファイル名はディスクの決まりで付くので `-o` は
使いません。両方を指定するとエラーになります。すでにディスクがあれば、そこに
足します。表の `--iso` から下はディスクについての指定なので、`--bdav` なしで
指定するとエラーになります。

| オプション | 意味 |
|---|---|
| `--bdav フォルダー` | このフォルダーに BDAV ディスクとして書きます（録画 1 本は `BDAV/STREAM/00001.m2ts` になります）。索引はそのあとで作られます |
| `--fit bd25\|bd50\|bd100\|bd128\|バイト数` | このサイズに収まるよう、映像を書き直して小さくします。収まっていれば何もしません。音声も字幕も番組情報もそのままで、小さくなるのは映像だけです。音声は書き出すときの形で計算するので、`--audio-codec lpcm` や `--drop-stream` で外したトラックも反映されます。MPEG-2 の録画だけが対象で、それ以外は原寸で書かれ、その旨が表示されます。原寸で収まらなければエラーで止まります。何割で書き直すかは書き出す前に表示されます。`--join` や `--sound-only` とは併用できません。[ディスク容量に合わせる](../technical/transrate.ja.md) |
| `--video-share 0.35..1` | 圧縮率を直接指定します。`--fit` が見積もりから求めるのと同じ値を、見積もりを通さずに与えます。`--fit` とは併用できません |
| `--iso 2.50\|2.60` | 書き終えたディスクを `.iso` に包んで同じ場所に置きます（`--bdav ~/disc` なら `~/disc/BDAV` と `~/disc.iso`）。フォルダーはそのまま残ります。その `.iso` が、いま録画を読んでいるイメージそのものなら、書き始める前にエラーになります |
| `--iso-access read-only\|overwritable` | そのイメージを焼いたディスクに何をしてよいかを書き分けます。既定の `read-only` は、もう書き込まないディスク向けの値です。BD-R や、再生するだけの BD-RE がこれにあたります。`overwritable` はレコーダーが BD-RE に書く値で、ディスクに録画を足したり消したりするとき、レコーダーはこちらを見ます。このときイメージはレコーダーが BD-RE に書くのと同じ配置になり、大きさもディスク全面（25 GB、1 層に収まらなければ 50 GB）になります。中身の無い部分は、書き出し先のディスクで場所を取りません。`--iso` と併用します |
| `--iso-only` | `.iso` を作ったあとフォルダーを消します。`--iso` と併用します。`.iso` はフォルダーから作るので、フォルダーが先に書かれ、`.iso` に収まってから消えます。消えるのは `BDAV` で、その上のフォルダーは空になったときだけ消えます。自分のフォルダーに直接書いた場合、そこにある他のものはそのままです。`BDAV` の中に `.iso` に入れられなかったファイルがあるときは、フォルダーを消しません |
| `--disc-title 名前` | ディスクの名前。省くとシリーズ名です（番組名から話数・サブタイトル・`[字]` などの記号を落としたもの）|
| `--programme 名前` | ディスクの管理情報に入る、この録画の名前。省くと、ディスクから読んだものはそのプレイリストの名前、放送録画は番組情報の番組名になります |
| `--channel 名前[,番号]` | 録ったチャンネル名と、任意で 3 桁の番号（`--channel "衛星第一,161"`）。省くと録画から取ります。番号が数字でなければエラーになります |
| `--about 説明` | ディスクの管理情報に入る番組内容。省くと録画の番組情報にある内容です |
| `--made "年-月-日 時:分:秒"` | 記録日時。省くと、録画に入っていればその番組の放送日時です |

## 調べる・確かめる

| オプション | 意味 |
|---|---|
| `--analyze` | 計画を立てて表示するだけで、**カットは書きません**。`--bdav` のフォルダーにも一切触れません。一緒に指定した `--seek-index`・`--proxy`・`--preview` のファイルは書きます |
| `--detect-cm` | CM の候補を探します |
| `--logo` | CM 検出でロゴも手がかりに使います |
| `--inserts` | CS の局が番組中に差し込む数秒（自局の動画 ID）も出します。既定はオフです。同じ判定で番組のテロップも拾うためで、詳しくは [CM 検出の説明](cm-detection.ja.md)をご覧ください |
| `--scenes` | 場面の変わり目を一覧します |
| `--preview 時刻` | その時刻のフレームを 1 枚 JPEG に書き出します（`preview.jpg`、または `-o`）。指定した時刻と、実際に取り出せた時刻の両方を表示します |
| `--cut-near 時刻` | その時刻にいちばん近い映像の切り替わり位置を、±0.5 秒・±1 秒・±2 秒の範囲それぞれについて表示します |

## 索引とプロキシ

| オプション | 意味 |
|---|---|
| `--seek-index パス` | 早送り用の索引の置き場所。初回に書き、2 回目からは読むので、録画を走査し直さずに済みます。別の版が書いたものや壊れたものは読めないので、作り直します |
| `--index auto\|disc\|scan\|container` | アクセスポイントをどこから得るか。既定の `auto` は、情報がすでにある場所から順に参照します。ディスク自身のマップ、コンテナのシークテーブル、最後にパケット走査の順です。`disc` と `container` はその 1 つだけを参照し、`scan` は必ず走査します（どちらのテーブルも持たない TS はこれになります）。コンテナのテーブルは、録画全体をカバーしているときだけ採用します |
| `--proxy` | 編集用のプロキシ（軽い代役ファイル）を録画と同じ名前で作って終わります（`.proxy.mp4`、または `-o`） |
| `--as-proxy` | 入力を録画ではなくプロキシとして扱います。プロキシが代役として成立しているかを確かめるためのものです |

## ディスクの字幕

| オプション | 意味 |
|---|---|
| `--subtitles pgs\|beside\|sup` | ディスクの字幕の行き先。既定の `pgs` は**カットの中**へ、TS が運べる種類として格納します（Blu-ray のものは無加工、DVD のものは変換して）。`beside` はカットとは別のファイルへ、プレーヤーも字幕ツールもそのまま読める `.idx` と `.sub` の 2 ファイルとして書きます（DVD のものは無加工、Blu-ray のものはディスプレイセットから読み戻して）。`sup` はそのディスプレイセットそのものを別ファイルの `.sup` に書きます（Blu-ray の字幕はバイト単位でそのまま。BDSup2Sub や Subtitle Edit が読む形式） |
| `--drop-subpicture ID` | DVD の字幕ストリームを 1 本除きます。ディスク上の id（`0x20`）で指定します。複数指定できます |

字幕を中に入れられるのは `.ts` と `.m2ts` だけです。`.mp4` を指定した場合はその旨を
表示して、代わりに 2 ファイルを別途書き出します。`.mp4` でディスクのカットが字幕を
保てるのは、この方法だけです。`.sup` は 1 ストリームしか持てないので、字幕が
2 本ある録画は 2 ファイルになり、言語で名前が付きます（`cut_title.eng.sup`）。
[ディスクの字幕](../technical/disc.ja.md#ディスクの字幕を焼き込むか別ファイルにするか)を参照してください。

## VC-1 のディスク

| オプション | 意味 |
|---|---|
| `--vc1-quant 3..31` | VC-1 で書かれた素材の、継ぎ目のフレームをどれだけ細かく書くか。3 が最も細かい設定です。既定は 4 で、置き換える元のフレームに対しておよそ 46 dB になります。オーバーラップ平滑化を使う素材では、8 より粗い値を指定しても 8 で書きます |

この設定が VC-1 にしか無いのは、**VC-1 のエンコーダがどこにも無い**からです。
FFmpeg にもグラフィックスカードにもありません。そこで継ぎ目のフレームだけは
SmartCut が自分で書いており、その細かさをここで指定します。詳しくは
[Rust コア](../technical/rust-core.ja.md#エンコーダのないコーデック-vc-1)にあります。
