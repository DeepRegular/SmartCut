# コマンドラインで使う

[← ドキュメント](../README.ja.md) ・ [← SmartCut](../../README.ja.md) ・ [English](cli.md)

GUI の中で動いているのと**同じエンジン**が、`smartcut` というコマンドとしても
使えます（deb で入れた場合は `smartcut-cli` という名前です。`smartcut` のほうは
GUI になります）。

決まった処理を繰り返すとき、スクリプトから呼ぶとき、あるいは画面を出せない
サーバーで使うときのためのものです。できることは GUI と同じです。

## まず、この 6 つ

```bash
smartcut input.ts --keep 5.3-12.7 -o out.ts   # この区間だけ残す
smartcut input.ts --cut 8.0-20.0  -o out.ts   # この区間を削除する
smartcut input.ts --analyze                   # 何が起きるかを表示するだけ

smartcut input.ts --analyze --detect-cm --logo  # CM の候補を一覧する
smartcut input.ts --analyze --scenes            # 場面の変わり目を一覧する

smartcut input.ts --cut 8.0-20.0 --bdav ~/disc  # ファイルではなくディスクに書く
```

- `--keep` と `--cut` は**何回でも書けます**。`--keep 0-60 --keep 180-240`
  のように並べれば、その 2 区間が残ります。
- 時刻は秒数のほか、`1:23:45.6` の形でも書けます。
- **`--analyze` は何も書きません。** どこをコピーしてどこを作り直すか、計画だけを
  表示します。まずこれで確かめてから本番を走らせるのが安全です。

## 切る場所を指定する

| オプション | 意味 |
|---|---|
| `--keep 開始-終了` | 残す区間。複数指定できます |
| `--cut 開始-終了` | 削除する区間。複数指定できます |
| `--no-open-gop` | 途中から始まるキーフレームを、コピーの開始点として使いません |
| `--clean-joins` | 各区間の先頭で最大 2 秒分を余分に作り直し、フレームの表示順が入れ替わらない位置まで進みます。**既定では使いません**（その 2 秒がコピーではなくなるためです。詳しくは下の注を見てください） |

> **`--clean-joins` の代償。** 通常の継ぎ目でも、コピーしたフレームそのものは元と
> 完全に同じです。ずれるのは表示される順番だけです。`--clean-joins` はそれを避ける
> ために 2 秒を作り直しますが、その 2 秒は元のコピーではなくなります（元に対して
> 約 51 dB）。確実な損で、不確実な得を買う取引になるので既定はオフです。

## 出力先を決める

| オプション | 意味 |
|---|---|
| `-o 出力パス` | 出力先。**コンテナ（ファイルの形式）は拡張子で決まります** |
| `--drop-stream 番号` | 録画のストリームを 1 本、出力から外します。複数指定できます。カット編集画面の**トラック**メニューと同じものです |
| `--title 番号` | ディスク（フォルダーでも `.iso` でも）の何番目の録画を開くか。番号のかわりに番組名の一部でも指定できます。**省くと、中身を一覧表示して終わります** |

## 音声

既定では、音声も映像と同じく**継ぎ目の数フレームだけ**を作り直します
（スマートレンダリング）。下の 5 つのうち 1 つでも録画と違う値を指定すると、
コピーできるフレームが無くなるので、**トラック全体が再エンコードになります**。

| オプション | 意味 |
|---|---|
| `--audio-mode smart\|copy\|reencode` | 既定は `smart`。継ぎ目にかかるフレームだけを作り直すので、切った側の音が漏れません。継ぎ目が無音なら 1 フレームも作り直しません。`copy` はバイト単位で無劣化ですが継ぎ目に音が少し残り、`reencode` はサンプル単位で正確に切れる代わりに全編を作り直します |
| `--audio-codec source\|aac\|lpcm\|ac3\|dts` | 書き出す音声の種類。既定の `source` は録画のままです。AAC はスマホでもそのまま鳴り、AC-3 と DTS は AV アンプが確実に鳴らし、リニア PCM は非圧縮です |
| `--audio-channels 数` | チャンネル数（1〜8）。録画と違う数を指定するとダウンミックスになります（5.1ch をステレオに畳む、など） |
| `--audio-samplerate レート` | サンプリング周波数。`48k` でも `48000` でも書けます。コーデックによって扱えるレートが違い（AC-3 は 3 種類、Blu-ray の LPCM は別の 3 種類）、扱えないものを指定した場合は、最も近い値に補正したうえで、その旨を表示します |
| `--audio-bits 16\|24` | 1 サンプルの大きさ。**リニア PCM のときだけ**意味を持ちます。ほかのコーデックは音そのものではなく音の表現方法を記録するので、ビット数を書く場所がありません |
| `--audio-bitrate レート` | 再エンコードするときのビットレート。`192k` でも `192000` でも書けます。省くと録画に合わせます。エンコーダが受け付けない値は、そのコーデックが通常使う値まで引き上げたうえで、その旨を表示します |
| `--aac auto\|mpeg2\|mpeg4` | 書き出す AAC がどちらの規格を名乗るか。既定の `auto` は録画に合わせます（放送なら MPEG-2 AAC） |
| `--audio-es` | 音声を素のファイルとしても書き出します。出力と同じ名前で、AAC のときだけです |
| `--audio-fade 秒数` | 継ぎ目の手前で音を下げ、継ぎ目の先で戻します。0〜10 秒、既定は 0（フェードなし）|

> **`--audio-fade` の効く範囲。** 音を書き直すときにだけ掛かります。`smart` と
> `reencode` では掛かり、`copy` では掛かりません。無劣化のまま運ぶ音声（TrueHD、
> DTS-HD MA）も書き直さないので掛かりません。掛からなかったときはその旨を表示します。
> 出力の先頭と末尾には掛かりません。フェードは 2 つの断片が出会う場所のためのものです。

## 放送 TS として書く

| オプション | 意味 |
|---|---|
| `--tables partial\|broadcast\|muxer` | TS が自分の中身をどう名乗るか。指定が無ければ `.ts` は `broadcast`（録画自身の SDT・EIT・TOT。プレーヤーが番組名・放送局名・時刻を読む場所）、`.m2ts` は `partial`（**部分 TS**。ディスクのストリームの書き方）になります。`muxer` は何も足しません。`--no-tables` は `muxer` の古い名前です |
| `--no-data-broadcast` | 録画のデータ放送（d ボタンで見られるページ）を捨てます。指定が無ければ残します。置けるのは放送自身の表を持つ `.ts` だけで、そこへはモジュールが欠けずにそのままのバイトで入るので、受信機は同じページを描きます。削除して得られるのはファイルサイズの削減です。カルーセルは多重化全体の 1/100 から 1/5 を占めます。`--data-broadcast` は明示的に指定する書き方で、格納できなかったときのメッセージだけが変わります |

## ディスク（BDAV）として書く

`--bdav` を使うと、ファイルではなく**レコーダーが BD-RE に書くのと同じ形**の
フォルダーに書き出します。ファイル名はディスクの決まりで付くので `-o` は
使いません。すでにディスクがあれば、そこに**足します**。

| オプション | 意味 |
|---|---|
| `--bdav フォルダー` | このフォルダーに BDAV ディスクとして書きます（録画 1 本は `BDAV/STREAM/00001.m2ts` になります）。索引はそのあとで作られます |
| `--fit bd25\|bd50\|bd100\|bd128\|バイト数` | このサイズに収まるよう、**映像を書き直して**小さくします。収まっていれば何もしません。音声も字幕も番組情報もそのままで、小さくなるのは映像だけです。MPEG-2 の録画だけが対象で、それ以外は原寸で書かれ、その旨が表示されます。何割で書き直すかは書き出す前に表示されます。[ディスク容量に合わせる](../technical/transrate.ja.md) |
| `--video-share 0.35..1` | 圧縮率を直接指定します。`--fit` が計算するのと同じ値で、こちらは見積もりを通しません |
| `--iso 2.50\|2.60` | 書き終えたディスクを `.iso` に包んで同じ場所に置きます（`--bdav ~/disc` なら `~/disc/BDAV` と `~/disc.iso`）。フォルダーはそのまま残ります |
| `--iso-access read-only\|overwritable` | そのイメージを焼いたディスクに何をしてよいかを書き分けます。既定の `read-only` は、もう書き込まないディスクに当てはまる値です。BD-R や、再生するだけの BD-RE がこれにあたります。`overwritable` はレコーダーが BD-RE に書く値で、ディスクに録画を足したり消したりするとき、レコーダーが見るのはこちらです。`--iso` と併用します |
| `--iso-only` | `.iso` を作ったあとフォルダーを消します。`--iso` と併用します。`.iso` はフォルダーから作るので、フォルダーは先に書かれ、`.iso` に収まってから消えます。消えるのは `BDAV` です。その上のフォルダーは空になったときだけ消えます。自分のフォルダーに直接書いた場合、そこにある他のものはそのままです |
| `--disc-title 名前` | ディスクの名前。省くとシリーズ名です（番組名から話数・サブタイトル・`[字]` などの記号を落としたもの）|
| `--programme 名前` | ディスクの管理情報に入る、この録画の名前。省くと、ディスクから読んだものはそのプレイリストの名前、放送録画は番組情報の番組名です |
| `--channel 名前[,番号]` | 録ったチャンネル名と、任意で 3 桁の番号（`--channel "衛星第一,161"`）。省くと録画から取ります |
| `--about 説明` | ディスクの管理情報に入る番組内容。省くと録画が持っている内容です |
| `--made "年-月-日 時:分:秒"` | 記録日時。省くと、録画に入っていればその番組の放送日時です |

## 調べる・確かめる

| オプション | 意味 |
|---|---|
| `--analyze` | 計画を立てて表示するだけで、**何も書きません**。`--bdav` のフォルダーにも一切触れません |
| `--detect-cm` | CM の候補を探します |
| `--logo` | CM 検出でロゴも手がかりに使います |
| `--scenes` | 場面の変わり目を一覧します |
| `--preview 時刻` | その時刻のフレームを 1 枚 JPEG に書き出します（`preview.jpg`、または `-o`）。指定した時刻と、実際に取り出せた時刻の両方を表示します |
| `--cut-near 時刻` | その時刻にいちばん近い映像の切り替わり位置を、±0.5 秒・±1 秒・±2 秒の範囲それぞれについて表示します |

## 索引とプロキシ

| オプション | 意味 |
|---|---|
| `--seek-index パス` | 早送り用の索引の置き場所。初回に書き、2 回目からは読むので、録画を走査し直さずに済みます |
| `--index auto\|disc\|scan\|container` | アクセスポイントをどこから得るか。既定の `auto` は、すでに情報を持っている側から順に参照します。ディスク自身のマップ、コンテナのシークテーブル、最後にパケット走査です。`disc` と `container` はその 1 つだけを参照し、`scan` は必ず走査します（どちらのテーブルも持たない TS はこれです）。コンテナのテーブルは、録画全体をカバーしているときだけ採用します |
| `--proxy` | 編集用のプロキシ（軽い代役ファイル）を録画と同じ名前で作って終わります（`.proxy.mp4`、または `-o`） |
| `--as-proxy` | 入力を録画ではなくプロキシとして扱います。プロキシが代役として成立しているかを確かめるためのものです |

## ディスクの字幕

| オプション | 意味 |
|---|---|
| `--subtitles pgs\|beside\|sup` | ディスクが描く字幕の行き先。既定の `pgs` は**カットの中**へ、TS が運べる種類として格納します（Blu-ray のものは無加工、DVD のものは変換して）。`beside` は**カットとは別のファイル**へ、プレーヤーも字幕ツールもそのまま読める `.idx` と `.sub` の 2 ファイルとして書きます（DVD のものは無加工、Blu-ray のものはディスプレイセットから読み戻して）。`sup` はそのディスプレイセットそのものを**別ファイルの `.sup`** に書きます（Blu-ray の字幕はバイト単位でそのまま。BDSup2Sub や Subtitle Edit が読む形式） |
| `--drop-subpicture ID` | DVD の字幕ストリームを 1 本除きます。ディスク上の id（`0x20`）で指定します。複数指定できます |

字幕を中に入れられるのは `.ts` と `.m2ts` だけです。`.mp4` を指定した場合はその旨を
表示して、代わりに 2 ファイルを別途書き出します。`.mp4` でディスクのカットが字幕を
保てるのは、この方法だけです。`.sup` は 1 ストリームしか持てないので、
字幕が 2 本ある録画は 2 ファイルになり、言語で名前が付きます（`cut_title.eng.sup`）。
[ディスクの字幕](../technical/disc.ja.md#ディスクの字幕を焼き込むか別ファイルにするか)を参照。

## VC-1 のディスク

| オプション | 意味 |
|---|---|
| `--vc1-quant 3..31` | VC-1 で書かれた素材の、継ぎ目のフレームをどれだけ細かく書くか。3 が最も細かい設定です。既定は 4 で、置き換える元のフレームに対しておよそ 46 dB になります |

この設定が VC-1 にしか無いのは、**VC-1 のエンコーダがどこにも無い**からです。
FFmpeg にもグラフィックスカードにもありません。そこで継ぎ目のフレームだけは SmartCut が
自分で書いており、その細かさをここで指定します。詳しくは
[Rust コア](../technical/rust-core.ja.md#エンコーダのないコーデック-vc-1)にあります。
